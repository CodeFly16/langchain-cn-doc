## 智能体框架（如 LangChain）

智能体框架提供抽象，使使用 LLM 构建变得更容易。

[LangChain](/oss/javascript/langchain/overview) 是一个智能体框架，提供结构化内容块、智能体循环和中间件等抽象。

LangChain 的抽象设计为易于上手，同时仍然为高级用例提供所需的灵活性。

虽然 LangChain 构建在 [LangGraph](/oss/javascript/langgraph/overview) 之上，但你无需了解 LangGraph 即可使用 LangChain。

其他智能体框架的例子包括 [Vercel AI SDK](https://ai-sdk.dev/docs/introduction)、[CrewAI](https://www.crewai.com/)、[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)、[Google ADK](https://google.github.io/adk-docs/)、[LlamaIndex](https://www.llamaindex.ai/) 等。

### 何时使用 LangChain

在以下情况使用 LangChain：

- 你想快速构建智能体和自主应用。
- 你需要模型、工具和智能体循环的标准抽象。
- 你想要一个易于使用但仍然灵活的框架。
- 你正在构建没有复杂编排需求的简单智能体应用。

## 智能体运行时（如 LangGraph）

智能体运行时提供在生产环境中运行智能体的工具。
支持的工具可能包括：

- **持久化执行**：智能体可以在故障中持久化并长时间运行，从中断处恢复。
- **流式输出**：支持工作流和响应的流式传输。
- **人机协作**：通过检查和修改智能体状态来纳入人工监督。
- **持久化**：线程级和跨线程的状态管理持久化。
- **底层控制**：无需高级抽象即可直接控制智能体编排。

[LangGraph](/oss/javascript/langgraph/overview) 是一个底层编排框架和运行时，用于构建、管理和部署长时间运行的有状态智能体。

智能体框架通常更高级别，运行在智能体运行时之上。
例如，LangChain 1.0 构建在 LangGraph 之上。

其他智能体运行时的例子包括 [Temporal](https://temporal.io/)、[Inngest](https://www.inngest.com/) 等持久化执行引擎。

### 何时使用 LangGraph

在以下情况使用 LangGraph：

- 你需要对智能体编排进行细粒度的底层控制。
- 你需要长时间运行的有状态智能体的持久化执行。
- 你正在构建结合确定性和智能体步骤的复杂工作流。
- 你需要用于智能体部署的生产就绪基础设施。

## 智能体工具集（如 Deep Agents SDK）

智能体工具集是带有内置工具和功能的有主见的、开箱即用的框架，用于构建复杂的长时间运行智能体。
支持的工具可能包括：

- **规划能力**：使用待办事项列表跟踪多个任务。
- **任务委托**：通过子智能体委托工作并保持上下文清洁。
- **文件系统**：在不同的可插拔存储后端上对文件进行读写访问。
- **Token 管理**：对话历史摘要和大型工具结果的清除。

[Deep Agents SDK](/oss/javascript/deepagents/overview) 构建在 LangGraph 之上，添加了规划能力、用于上下文管理的文件系统、生成子智能体的能力等。
深度智能体专为需要规划和分解的复杂多步骤任务设计。

示例任务包括处理搜索结果、脚本和状态中的其他工件。

其他智能体工具集的例子包括 [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview)、[Manus](https://manus.im/) 和其他编程 CLI。

### 何时使用 Deep Agents SDK

在以下情况使用 [Deep Agents SDK](/oss/javascript/deepagents/overview)：

- 你正在构建长时间运行的智能体。
- 你正在构建需要处理复杂多步骤任务的智能体。
- 你想使用预定义的工具，如文件系统操作、bash 执行和自动化上下文工程。
- 你想使用预定义的提示和子智能体。

## 功能比较

虽然你可以使用 LangChain、LangGraph 和深度智能体完成类似的任务，但集成的层次不同：

| 功能 | LangChain | LangGraph   | Deep Agents |
| ------- | --------- | ----------- | ----------- |
| 短期记忆 | [短期记忆](/oss/javascript/langchain/short-term-memory) | [短期记忆](/oss/javascript/langgraph/add-memory#add-short-term-memory) | [`StateBackend`](/oss/javascript/deepagents/backends#statebackend) |
| 长期记忆 | [长期记忆](/oss/javascript/langchain/long-term-memory) | [长期记忆](/oss/javascript/langgraph/add-memory#add-long-term-memory) | [长期记忆](/oss/javascript/deepagents/memory) |
| 技能  | [多智能体技能](/oss/javascript/langchain/multi-agent/skills) | - | [技能](/oss/javascript/deepagents/skills) |
| 子智能体 | [多智能体子智能体](/oss/javascript/langchain/multi-agent/subagents) | [子图](/oss/javascript/langgraph/use-subgraphs) | [子智能体](/oss/javascript/deepagents/subagents) |
| 人机协作 | [人机协作中间件](/oss/javascript/langchain/human-in-the-loop) | [中断](/oss/javascript/langgraph/interrupts) | [`interrupt_on` 参数](/oss/javascript/deepagents/harness#human-in-the-loop) |
| 流式输出 | [智能体流式输出](/oss/javascript/langchain/streaming/overview) | [流式输出](/oss/javascript/langgraph/streaming) | [流式输出](/oss/javascript/deepagents/streaming/overview) |
