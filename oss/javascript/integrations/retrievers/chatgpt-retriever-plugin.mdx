This example shows how to use the ChatGPT Retriever Plugin within LangChain.

To set up the ChatGPT Retriever Plugin, follow the [ChatGPT Retrieval Plugin setup instructions](https://github.com/openai/chatgpt-retrieval-plugin).

## 用法

```typescript
import { ChatGPTPluginRetriever } from "@langchain/classic/retrievers/remote";

const retriever = new ChatGPTPluginRetriever({
  url: "http://0.0.0.0:8000",
  auth: {
    bearer: "super-secret-jwt-token-with-at-least-32-characters-long",
  },
});

const docs = await retriever.invoke("hello world");

console.log(docs);
```
