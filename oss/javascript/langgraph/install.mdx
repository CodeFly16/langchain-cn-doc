sidebarTitle: 安装

安装 LangGraph 基础包：



<CodeGroup>
```bash npm
npm install @langchain/langgraph @langchain/core
```

```bash pnpm
pnpm add @langchain/langgraph @langchain/core
```

```bash yarn
yarn add @langchain/langgraph @langchain/core
```

```bash bun
bun add @langchain/langgraph @langchain/core
```
</CodeGroup>


使用 LangGraph 时，你通常需要访问大语言模型(LLM)并定义工具。
你可以使用任何你觉得合适的方式来实现。

其中一种方式（也是我们在文档中使用的方式）是使用 [LangChain](/oss/javascript/langchain/overview)。

使用以下命令安装 LangChain：



<CodeGroup>
```bash npm
npm install langchain
```

```bash pnpm
pnpm add langchain
```

```bash yarn
yarn add langchain
```

```bash bun
bun add langchain
```
</CodeGroup>


要使用特定的 LLM 提供商包，你需要单独安装它们。

请参阅[集成](/oss/javascript/integrations/providers/overview)页面获取特定提供商的安装说明。
