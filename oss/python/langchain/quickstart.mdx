    from langchain.agents import create_agent

    def get_weather(city: str) -> str:
        """Get weather for a given city."""
        return f"It's always sunny in {city}!"

    agent = create_agent(
        model="openai:gpt-5.4",
        tools=[get_weather],
        system_prompt="You are a helpful assistant",
    )

    result = agent.invoke(

## 构建真实世界的智能体

在以下示例中，你将构建一个能够回答有关文本文件问题的研究智能体。
在此过程中，你将探索以下概念：

1. **详细的系统提示词**以获得更好的智能体行为
1. **创建工具**与外部数据集成
1. **模型配置**以获得一致的响应
1. **对话记忆**实现类聊天交互
1. **Deep Agents** 的内置功能
1. **测试**你的智能体

    <Step title="定义系统提示词">
        系统提示词定义了智能体的角色和行为。保持其具体且可操作：

        ```python wrap
        SYSTEM_PROMPT = """You are a literary data assistant.

        ## Capabilities

        - `fetch_text_from_url`: loads document text from a URL into the conversation.
        Do not guess line counts or positions—ground them in tool results from the saved file."""
        ```



    </Step>
    <Step title="创建工具">
        [工具](/oss/python/langchain/tools)让模型能够通过调用你定义的函数与外部系统交互。
        工具可以依赖[运行时上下文](/oss/python/langchain/runtime)，也可以与[智能体记忆](/oss/python/langchain/short-term-memory)交互。

        此示例使用一个工具从给定 URL 加载文档：

        ```python
        import urllib.error
        import urllib.request

        from langchain.tools import tool


        @tool
        def fetch_text_from_url(url: str) -> str:
            """Fetch the document from a URL.
            """
            req = urllib.request.Request(
                url,
                headers={"User-Agent": "Mozilla/5.0 (compatible; quickstart-research/1.0)"},
            )
            try:
                with urllib.request.urlopen(req, timeout=120) as resp:
                    raw = resp.read()
            except urllib.error.URLError as e:
                return f"Fetch failed: {e}"
            text = raw.decode("utf-8", errors="replace")
            return text
        ```

        <Tip>
            工具应该有良好的文档说明：它们的名称、描述和参数名称会成为模型提示词的一部分。
            LangChain 的 [`@tool` 装饰器](https://reference.langchain.com/python/langchain-core/tools/convert/tool)添加了元数据，并通过 `ToolRuntime` 参数启用运行时注入。
            在[工具指南](/oss/python/langchain/tools)中了解更多。
        </Tip>

    <Step title="创建并运行智能体">

        现在用所有组件组装你的智能体并运行它。

        创建智能体有两种不同的框架：LangChain 智能体和 Deep Agents。
        LangChain 智能体和 Deep Agents 都提供了对工具、记忆等的细粒度控制。
        两者的主要区别在于 Deep Agents 内置了一系列常用功能，如规划、文件系统工具和子智能体。

        当你想要以最少的设置获得最大能力时使用 Deep Agents；当你需要细粒度控制时选择 LangChain 智能体。

        <Warning>
            由于代码使用《了不起的盖茨比》的完整文本调用模型，它会使用大量 Token。

            你可以在下一步中查看示例输出。
        </Warning>

        让我们尝试两种方式：

        ```python wrap
        import urllib.error
        import urllib.request

        from langchain.agents import create_agent
        from deepagents import create_deep_agent
        from langchain.chat_models import init_chat_model
        from langchain.tools import tool
        from langgraph.checkpoint.memory import InMemorySaver

        SYSTEM_PROMPT = """You are a literary data assistant.

        ## Capabilities

        - `fetch_text_from_url`: loads document text from a URL into the conversation.
        Do not guess line counts or positions—ground them in tool results from the saved file."""


        @tool
        def fetch_text_from_url(url: str) -> str:
            """Fetch the document from a URL.
            """
            req = urllib.request.Request(
                url,
                headers={"User-Agent": "Mozilla/5.0 (compatible; quickstart-research/1.0)"},
            )
            try:
                with urllib.request.urlopen(req, timeout=120) as resp:
                    raw = resp.read()
            except urllib.error.URLError as e:
                return f"Fetch failed: {e}"
            text = raw.decode("utf-8", errors="replace")
            return text


        model = init_chat_model(
            "gemini-3.1-pro-preview",
            model_provider="google-genai",
            temperature=0.5,
            timeout=600,
            max_tokens=25000,
            streaming=True,
        )

        checkpointer = InMemorySaver()

        agent = create_agent(
            model=model,
            tools=[fetch_text_from_url],
            system_prompt=SYSTEM_PROMPT,
            checkpointer=checkpointer,
        )

        deep_agent = create_deep_agent(
            model=model,
            tools=[fetch_text_from_url],
            system_prompt=SYSTEM_PROMPT,
            checkpointer=checkpointer,
        )

        content = f"""Project Gutenberg hosts a full plain-text copy of F. Scott Fitzgerald's The Great Gatsby.
        URL: https://www.gutenberg.org/files/64317/64317-0.txt

        Answer as much as you can:

        1) How many lines in the complete Gutenberg file contain the substring `Gatsby` (count lines, not occurrences within a line, each line ends with a line break).
        2) The 1-based line number of the first line in the file that contains `Daisy`.
        3) A two-sentence neutral synopsis.

        Do your best on (1) and (2). If at any point you realize you cannot **verify** an exact answer with
        your available tools and reasoning, do not fabricate numbers: use `null` for that field and spell out
        the limitation in `how_you_computed_counts`. If you encounter any errors please report what the error was and what the error message was."""

        agent_result = agent.invoke(
            {"messages": [{"role": "user", "content": content}]},

        )
        deep_agent_result = deep_agent.invoke(
            {"messages": [{"role": "user", "content": content}]},
            config={"configurable": {"thread_id": "great-gatsby-da"}},
        )
        print(agent_result["messages"][-1].content_blocks)
        print("\n")
        print(deep_agent_result["messages"][-1].content_blocks)
        ```

        </Tabs>

        如果你查看两个标签页的输出，会注意到 LangChain 智能体提供了答案但都是估计值。该智能体缺少回答这个问题所需的工具。你可能还会收到提示词过长的错误。

        另一方面，Deep Agent 能够：

        1. **规划其方法**，使用内置的 [`write_todos`](/oss/python/deepagents/harness#planning-capabilities) 工具来分解研究任务。
        1. **加载文件**，通过调用 `fetch_text_from_url` 工具来收集信息。
        1. **管理上下文**，使用文件系统工具（[`grep`](/oss/python/deepagents/harness#virtual-filesystem-access) 和 [`read_file`](/oss/python/deepagents/harness#virtual-filesystem-access)）。
        1. **派生子智能体**，根据需要将复杂子任务委派给专门的子智能体。

        对于 LangChain 智能体，你必须实现更多功能才能获得类似的服务水平，并且可以根据需要在过程中对其进行自定义。

    </Step>
</Steps>

## 追踪智能体调用

你使用 LangChain 构建的大多数有趣应用程序会对大语言模型(LLM)进行多次调用。随着这些应用程序变得更加复杂，能够检查智能体内部到底发生了什么变得越来越重要。最好的方式是使用 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langchain-quickstart)。

注册一个 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langchain-quickstart) 账户并设置以下变量开始记录追踪：

```shell
export LANGSMITH_TRACING="true"
export LANGSMITH_API_KEY="..."
```

设置完成后，重新运行你的脚本，然后在 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langchain-quickstart) 上检查智能体调用期间发生了什么。

<Tip>
    要了解更多关于使用 LangSmith 追踪智能体的信息，请参阅 [LangSmith 文档](/langsmith/trace-with-langchain)。
</Tip>
