长期记忆允许你的智能体跨不同对话和会话存储及检索信息。
与[短期记忆](/oss/python/langchain/short-term-memory)不同——短期记忆的作用范围仅限于单个线程——长期记忆可以跨线程持久化，并且可以随时检索。

长期记忆构建在 [LangGraph 存储](/oss/python/langgraph/persistence#memory-store)之上，它将数据保存为按命名空间和键组织的 JSON 文档。

## 使用方法

要为智能体添加长期记忆，需要创建一个存储并将其传递给 [`create_agent`](https://reference.langchain.com/python/langchain/agents/factory/create_agent)：

## 记忆存储

LangGraph 将长期记忆存储为[存储](/oss/python/langgraph/persistence#memory-store)中的 JSON 文档。

每条记忆组织在自定义的 `namespace`（类似于文件夹）和唯一的 `key`（类似于文件名）下。命名空间通常包含用户 ID 或组织 ID 或其他标签，以便更轻松地组织信息。

这种结构支持记忆的层次化组织。然后通过内容过滤器支持跨命名空间搜索。
