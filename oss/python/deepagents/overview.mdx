深度智能体是一个开源智能体 Harness，用于构建能够规划、使用工具和委派子智能体的长时间运行的智能体。它提供了一个完整的框架，包括虚拟文件系统、上下文管理、技能系统和记忆功能。

## 核心功能

- **规划能力** - 内置 `write_todos` 工具，用于维护结构化的任务列表
- **虚拟文件系统** - 可配置的文件系统后端，支持 `ls`、`read_file`、`write_file`、`edit_file`、`glob`、`grep` 等操作
- **子智能体** - 通过 `task` 工具将工作委派给专门的子智能体，实现上下文隔离
- **上下文管理** - 自动卸载和摘要功能，在 Token 限制内保持上下文
- **技能** - 按需加载的可复用智能体能力
- **记忆** - 跨对话持久化的 `AGENTS.md` 文件
- **人机协作** - 可配置的工具操作审批门控
- **代码执行** - 通过沙箱后端或解释器执行代码
