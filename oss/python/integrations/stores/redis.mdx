## 概述

`RedisStore` 是 `ByteStore` 的实现，将所有内容存储在你的 Redis 实例中。

## 设置

要创建 Redis 字节存储，你需要设置一个 Redis 实例。 你可以在本地或通过提供商来完成此操作 - 请参阅我们的 [Redis guide](/oss/python/integrations/providers/redis) 了解可用选项的概述。

### 安装

The LangChain `RedisStore` integration lives in the `langchain-community` package:

```python
pip install -qU langchain-community redis
```

## Instantiation

Now we can instantiate our byte store:

```python
from langchain_community.storage import RedisStore

kv_store = RedisStore(redis_url="redis://localhost:6379")
```

## 使用方法

You can set data under keys like this using the `mset` method:

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[b'value1', b'value2']
```

And you can delete data using the `mdelete` method:

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[None, None]
```
