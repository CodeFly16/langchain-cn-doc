本笔记本展示如何将 LangChain 与 [LlamaAPI](https://llama-api.com/) 配合使用 - 这是 Llama2 的托管版本，增加了函数调用支持。

pip install -qU  llamaapi

```python
from llamaapi import LlamaAPI

# 将 'Your_API_Token' 替换为您的实际 API Token
llama = LlamaAPI("Your_API_Token")
```

```python
from langchain_experimental.llms import ChatLlamaAPI
```

```python
from langchain_classic.chains import create_tagging_chain

schema = {
    "properties": {
        "sentiment": {
            "type": "string",
            "description": "文本中的情感倾向",
        },
        "aggressiveness": {
            "type": "integer",
            "description": "文本的攻击性评分，0-10 分",
        },
        "language": {"type": "string", "description": "文本的语言"},
    }
}

chain = create_tagging_chain(schema, model)
```

```python
chain.run("give me your money")
```
