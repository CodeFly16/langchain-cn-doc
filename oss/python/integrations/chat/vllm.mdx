vLLM can be deployed as a server that mimics the OpenAI API protocol. This allows vLLM to be used as a drop-in replacement for applications using OpenAI API. This server can be queried in the same format as OpenAI API.

## 概述

本指南将帮助您开始使用 vLLM [聊天模型](/oss/python/langchain/models), which leverages the `langchain-openai` package. 有关所有 [`ChatOpenAI`](https://reference.langchain.com/python/langchain-openai/chat_models/base/ChatOpenAI) 功能和配置的详细文档，请前往 [API reference](https://reference.langchain.com/python/langchain-openai/chat_models/base/ChatOpenAI).

### 模型功能

Specific model features, such as tool calling, support for multi-modal inputs, support for token-level streaming, etc., will depend on the hosted model.

## 设置

请参阅 [vLLM documentation](https://docs.vllm.ai/en/latest/).

要访问 vLLM models through LangChain, you'll need to install the `langchain-openai` 集成包。

### 凭证

Authentication will depend on specifics of the inference server.

要启用模型调用的自动追踪，请设置您的 [LangSmith](/langsmith/home) API key:

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("请输入您的 LangSmith API 密钥: ")
```

### 安装

LangChain 的 vLLM integration can be accessed 通过 `langchain-openai` 包中：

```python
pip install -qU langchain-openai
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain.messages import HumanMessage, SystemMessage
from langchain_openai import ChatOpenAI
```

```python
inference_server_url = "http://localhost:8000/v1"

llm = ChatOpenAI(
    model="mosaicml/mpt-7b",
    api_key="your api key goes here",
    base_url=inference_server_url,
    max_tokens=5,
    temperature=0,
)
```

## 调用

```python
messages = [
    SystemMessage(
        content="You are a helpful assistant that translates English to Italian."
    ),
    HumanMessage(
        content="Translate the following sentence from English to Italian: I love programming."
    ),
]
llm.invoke(messages)
```

```text

```
