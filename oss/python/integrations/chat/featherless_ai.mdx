## 设置

要访问 Featherless AI 模型，您需要创建一个 Featherless AI 账户，获取 API 密钥，并安装 `langchain-featherless-ai` 集成包。

### 凭证

前往 [featherless.ai/](https://featherless.ai/) 注册 FeatherlessAI 并生成 API 密钥。 完成后设置 FEATHERLESSAI_API_KEY 环境变量：

```python
import getpass
import os

if not os.getenv("FEATHERLESSAI_API_KEY"):
    os.environ["FEATHERLESSAI_API_KEY"] = getpass.getpass(
        "Enter your FeatherlessAI API key: "
    )
```

如果您想对模型调用进行自动追踪，还可以设置您的 [LangSmith](/langsmith/home) API key by uncommenting below:

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("请输入您的 LangSmith API 密钥: ")
```

### 安装

LangChain 的 FeatherlessAi 集成位于 `langchain-featherless-ai` 包中：

```python
pip install -qU langchain-featherless-ai
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_featherless_ai import ChatFeatherlessAi

llm = ChatFeatherlessAi(
    model="featherless-ai/Qwerky-72B",
    temperature=0.9,
    max_tokens=None,
    timeout=None,
)
```

messages = [
