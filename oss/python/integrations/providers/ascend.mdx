>[Ascend](https://https://www.hiascend.com/) is Natural Process Unit provide by Huawei

This page covers how to use ascend NPU与 LangChain 配合使用。

### 安装

Install using torch-npu using:

<CodeGroup>
```bash pip
pip install torch-npu
```

```bash uv
uv add torch-npu
```
</CodeGroup>

请按照以下安装说明操作：
* Install CANN as shown in the [CANN installation documentation](https://www.hiascend.com/document/detail/zh/canncommercial/700/quickstart/quickstart/quickstart_18_0002.html).

### 向量嵌入模型

查看[使用示例](/oss/python/integrations/embeddings/ascend).

from langchain_community.embeddings import AscendEmbeddings
