>[Jina AI](https://jina.ai/about-us) is a search AI company. `Jina` helps businesses and developers unlock multimodal data with a better search.

<Warning>
For proper compatibility, please ensure you are 使用 `openai` SDK at version **0.x**.
</Warning>

## 安装和设置
- Get a Jina AI API token from the [Jina AI embeddings page](https://jina.ai/embeddings/) and set it as an environment variable (`JINA_API_TOKEN`)

## 聊天模型

```python
from langchain_community.chat_models import JinaChat
```

See a [usage examples](/oss/python/integrations/chat/jinachat).

## 向量嵌入模型

您可以查看 the list of available models on the [Jina AI embeddings page](https://jina.ai/embeddings/)

```python
from langchain_community.embeddings import JinaEmbeddings
```

See a [usage examples](/oss/python/integrations/embeddings/jina).

## 文档转换器

### Jina rerank

```python
from langchain_community.document_compressors import JinaRerank
```

See a [usage examples](/oss/python/integrations/document_transformers/jina_rerank).
