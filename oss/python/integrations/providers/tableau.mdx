[Tableau](https://www.tableau.com/) is an analytics platform that enables anyone to
see and understand data.


## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-tableau
```

```bash uv
uv add langchain-tableau
```
</CodeGroup>
