>[Vespa](https://vespa.ai/) is a fully featured search engine and vector database.
> 它支持 vector search (ANN), lexical search, and search in structured data, all in the same query.

## 安装和设置


<CodeGroup>
```bash pip
pip install pyvespa
```

```bash uv
uv add pyvespa
```
</CodeGroup>
