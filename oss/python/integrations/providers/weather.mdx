>[OpenWeatherMap](https://openweathermap.org/) 是一个开源的 weather service provider.



## 安装和设置

<CodeGroup>
```bash pip
pip install pyowm
```

```bash uv
uv add pyowm
```
</CodeGroup>

We must set up the `OpenWeatherMap API token`.

## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/weather).

```python
from langchain_community.document_loaders import WeatherDataLoader
```
