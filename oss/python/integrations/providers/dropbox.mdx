>[Dropbox](https://en.wikipedia.org/wiki/Dropbox) is a file hosting service that brings everything-traditional
> files, cloud content, and web shortcuts together in one place.


## 安装和设置

See the detailed [installation guide](/oss/python/integrations/document_loaders/dropbox#prerequisites).

<CodeGroup>
```bash pip
pip install -U dropbox
```

```bash uv
uv add dropbox
```
</CodeGroup>

## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/dropbox).

```python
from langchain_community.document_loaders import DropboxLoader
```
