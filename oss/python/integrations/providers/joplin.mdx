>[Joplin](https://joplinapp.org/) 是一个开源的 note-taking app. It captures your thoughts
> and securely accesses them from any device.


## 安装和设置

The `Joplin API` requires an access token.
您可以找到 installation instructions in the [Joplin REST API documentation](https://joplinapp.org/api/references/rest_api/).
