## 安装和设置

Get the access token.
您可以找到 the access instructions in the [Lark open platform documentation](https://open.larksuite.com/document).

## 文档加载器

>[Lark Suite](https://www.larksuite.com/) is an enterprise collaboration platform
> developed by `ByteDance`.

### Lark suite for document

查看[使用示例](/oss/python/integrations/document_loaders/larksuite/#load-from-document).

```python
from langchain_community.document_loaders.larksuite import LarkSuiteDocLoader
```

### Lark suite for wiki

查看[使用示例](/oss/python/integrations/document_loaders/larksuite/#load-from-wiki).

```python
from langchain_community.document_loaders.larksuite import LarkSuiteWikiLoader
```
