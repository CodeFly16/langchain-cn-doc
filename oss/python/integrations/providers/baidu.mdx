本页面涵盖了 LangChain 与Baidu products, such as PaddleOCR.

## PaddleOCR

The `langchain-paddleocr` package implements integrations of PaddleOCR's capabilities. [PaddleOCR](https://www.paddleocr.com) is a powerful and lightweight OCR toolkit developed by Baidu that connects images and PDFs with LLMs. 它支持 over 100 languages and transforms document content into structured, AI-ready data.

## Baidu AI Cloud

### 安装和设置

Register and get the `Qianfan` `AK` and `SK` keys from [Baidu Cloud Wenxin Workshop](https://cloud.baidu.com/product/wenxinworkshop).

### 大语言模型 (LLM)

#### Baidu qianfan

查看[使用示例](/oss/python/integrations/llms/baidu_qianfan_endpoint).

```python
from langchain_community.llms import QianfanLLMEndpoint
```

### 聊天模型

#### Qianfan chat endpoint

查看[使用示例](/oss/python/integrations/chat/baidu_qianfan_endpoint).
See another [usage example](/oss/python/integrations/chat/ernie).

```python
from langchain_community.chat_models import QianfanChatEndpoint
```

### 向量嵌入模型

#### Baidu qianfan

查看[使用示例](/oss/python/integrations/embeddings/baidu_qianfan_endpoint).
See another [usage example](/oss/python/integrations/embeddings/ernie).

```python
from langchain_community.embeddings import QianfanEmbeddingsEndpoint
```

### 文档加载器

#### Baidu BOS directory loader

```python
from langchain_community.document_loaders.baiducloud_bos_directory import BaiduBOSDirectoryLoader
```

#### Baidu BOS file loader

```python
from langchain_community.document_loaders.baiducloud_bos_file import BaiduBOSFileLoader
```

### 向量存储

#### Baidu cloud ElasticSearch VectorSearch

查看[使用示例](/oss/python/integrations/vectorstores/baiducloud_vector_search).


#### Baidu VectorDB

查看[使用示例](/oss/python/integrations/vectorstores/baiduvectordb).
