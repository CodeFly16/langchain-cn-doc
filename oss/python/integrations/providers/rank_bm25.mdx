[rank_bm25](https://github.com/dorianbrown/rank_bm25) 是一个开源的 collection of algorithms
designed to query documents and return the most relevant ones, commonly used for creating
search engines.

See its [project page](https://github.com/dorianbrown/rank_bm25) for available algorithms.


## 安装和设置

First, you need to install `rank_bm25` Python 包.

<CodeGroup>
```bash pip
pip install rank_bm25
```

```bash uv
uv add rank_bm25
```
</CodeGroup>


## 检索器

查看[使用示例](/oss/python/integrations/retrievers/bm25).

```python
from langchain_community.retrievers import BM25Retriever
```
