>[Argilla](https://argilla.io/) 是一个开源的 data curation platform for LLMs.
> Using `Argilla`, everyone can build robust language models through faster data curation
> using both human and machine feedback. `Argilla` provides support for each step in the MLOps cycle,
> from data labeling to model monitoring.

## 安装和设置

Get your [API key](https://platform.openai.com/account/api-keys).

安装 Python 包：

<CodeGroup>
```bash pip
pip install argilla
```

```bash uv
uv add argilla
```
</CodeGroup>

## 回调


```python
from langchain.callbacks import ArgillaCallbackHandler
```

See an [example](/oss/python/integrations/callbacks/argilla).
