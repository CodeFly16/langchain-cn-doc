>[Weaviate](https://weaviate.io/) 是一个开源的 vector database. 它允许 you to store data objects and vector embeddings from
>your favorite ML models, and scale seamlessly into billions of data objects.


What is `Weaviate`?
- Weaviate 是一个开源的 ​database of the type ​vector search engine.
- Weaviate allows you to store JSON documents in a class property-like fashion while attaching machine learning vectors to these documents to represent them in vector space.
- Weaviate can be used stand-alone (aka bring your vectors) or with a variety of modules that can do the vectorization for you and extend the core capabilities.
- Weaviate has a GraphQL-API to access your data easily.
- We aim to bring your vector search set up to production to query in mere milliseconds (check our [open-source benchmarks](https://weaviate.io/developers/weaviate/current/benchmarks/) to see if Weaviate fits your use case).
- Get to know Weaviate in the [basics getting started guide](https://weaviate.io/developers/weaviate/current/core-knowledge/basics.html) in under five minutes.

**Weaviate in detail:**

`Weaviate` is a low-latency vector search engine with out-of-the-box support for different media types (text, images, etc.). 它提供 Semantic Search, Question-Answer Extraction, Classification, Customizable Models (PyTorch/TensorFlow/Keras), etc. Built from scratch in Go, Weaviate stores both objects and vectors, allowing for combining vector search with structured filtering and the fault tolerance of a cloud-native database. It is all accessible through GraphQL, REST, and various client-side programming languages.

## 安装和设置

安装 Python SDK：

<CodeGroup>
```bash pip
pip install langchain-weaviate
```

```bash uv
uv add langchain-weaviate
```
</CodeGroup>


## 向量存储

存在一个围绕 `Weaviate` indexes, 的封装器，允许您将其用作向量存储，
无论是用于语义搜索还是示例选择。

要导入此向量存储：
```python
from langchain_weaviate import WeaviateVectorStore
```

有关 Weaviate 封装器的更详细演练，请参阅[此笔记本](/oss/python/integrations/vectorstores/weaviate)
