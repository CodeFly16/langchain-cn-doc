>[E2B](https://e2b.dev/) provides open-source secure sandboxes
> for AI-generated code execution. See more on the [e2b GitHub repository](https://github.com/e2b-dev).

## 安装和设置

您需要安装 a Python 包:

<CodeGroup>
```bash pip
pip install e2b_code_interpreter
```

```bash uv
uv add e2b_code_interpreter
```
</CodeGroup>

## 工具

查看[使用示例](/oss/python/integrations/tools/e2b_data_analysis).

```python
from langchain_community.tools import E2BDataAnalysisTool
```
