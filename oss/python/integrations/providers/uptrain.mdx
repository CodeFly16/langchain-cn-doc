>[UpTrain](https://uptrain.ai/) 是一个开源的 unified platform to evaluate and
>improve Generative AI applications. 它提供 grades for 20+ preconfigured evaluations
>(covering language, code, embedding use cases), performs root cause analysis on failure
>cases and gives insights on how to resolve them.

## 安装和设置

<CodeGroup>
```bash pip
pip install uptrain
```

```bash uv
uv add uptrain
```
</CodeGroup>

## 回调

```python
from langchain_community.callbacks.uptrain_callback import UpTrainCallbackHandler
```

See an [example](/oss/python/integrations/callbacks/uptrain).
