>[Trello](https://www.atlassian.com/software/trello) is a web-based project management and collaboration tool that allows individuals and teams to organize and track their tasks and projects. 它提供 a visual interface known as a "board" where users can create lists and cards to represent their tasks and activities.
>The TrelloLoader allows us to load cards from a `Trello` board.


## 安装和设置

<CodeGroup>
```bash pip
pip install py-trello beautifulsoup4
```

```bash uv
uv add py-trello beautifulsoup4
```
</CodeGroup>

See [setup instructions](/oss/python/integrations/document_loaders/trello).


## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/trello).

```python
from langchain_community.document_loaders import TrelloLoader
```
