>[KoNLPy](https://konlpy.org/) is a Python 包 for natural language processing (NLP)
> of the Korean language.


## 安装和设置

您需要安装 the `konlpy` Python 包.

<CodeGroup>
```bash pip
pip install konlpy
```

```bash uv
uv add konlpy
```
</CodeGroup>

## 文本分割器


```python
from langchain_text_splitters import KonlpyTextSplitter
```
