>[spaCy](https://spacy.io/) 是一个开源的 software library for advanced natural language processing, written in the programming languages Python and Cython.

## 安装和设置


<CodeGroup>
```bash pip
pip install spacy
```

```bash uv
uv add spacy
```
</CodeGroup>



## 文本分割器

```python
from langchain_text_splitters import SpacyTextSplitter
```

## 文本向量嵌入模型

查看[使用示例](/oss/python/integrations/embeddings/spacy_embedding)

```python
from langchain_community.embeddings.spacy_embeddings import SpacyEmbeddings
```
