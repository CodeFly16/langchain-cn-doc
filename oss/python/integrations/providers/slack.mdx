>[Slack](https://slack.com/) is an instant messaging program.

## 安装和设置

无需任何特殊设置。


## 文档加载器

查看[使用示例](/oss/python/integrations/document_loaders/slack).

```python
from langchain_community.document_loaders import SlackDirectoryLoader
```

## 工具包

查看[使用示例](/oss/python/integrations/tools/slack).

```python
from langchain_community.agent_toolkits import SlackToolkit
```

## Chat loader

查看[使用示例](/oss/python/integrations/chat_loaders/slack).

```python
from langchain_community.chat_loaders.slack import SlackChatLoader
```
