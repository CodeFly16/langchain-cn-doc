>[DuckDB](https://duckdb.org/) is an in-process SQL OLAP database management system.

## 安装和设置

First, you need to install `duckdb` Python 包.

<CodeGroup>
```bash pip
pip install duckdb
```

```bash uv
uv add duckdb
```
</CodeGroup>

## 文档加载器

```python
from langchain_community.document_loaders import DuckDBLoader
```
