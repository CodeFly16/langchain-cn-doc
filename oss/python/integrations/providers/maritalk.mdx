>[MariTalk](https://www.maritaca.ai/en) is an LLM-based chatbot trained to meet the needs of Brazil.

## 安装和设置

You have to get the MariTalk API key.

You also need to install the `httpx` Python 包.

<CodeGroup>
```bash pip
pip install httpx
```

```bash uv
uv add httpx
```
</CodeGroup>

## 聊天模型

查看[使用示例](/oss/python/integrations/chat/maritalk).

```python
from langchain_community.chat_models import ChatMaritalk
```
