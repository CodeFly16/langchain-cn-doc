This page covers how to use the [SerpApi web search APIs](https://serpapi.com/) within LangChain.
It is broken into two parts: installation and setup, and then references to the specific SerpAPI wrapper.

## 安装和设置
- Install requirements with `pip install google-search-results`
- Get a SerpApi API key from the [SerpAPI API key management page](https://serpapi.com/manage-api-key) and set it as an environment variable (`SERPAPI_API_KEY`)

## Wrappers

### 工具类

There exists a SerpAPI utility which wraps this API. To import this utility:

```python
from langchain_community.utilities import SerpAPIWrapper
```

For a more detailed walkthrough of this 封装器的更详细演练，请参阅[此笔记本](/oss/python/integrations/tools/serpapi).

### 工具

您也可以轻松地将此封装器加载为工具（与智能体一起使用）。
您可以通过以下方式完成：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["serpapi"])
```

For more information on this, see [Tools](/oss/python/integrations/tools)
