This page covers how to use the [cloro](https://cloro.dev/) monitoring APIs within LangChain.

## 安装和设置
- Install requirements with `pip install -U langchain-cloro`
- Get a cloro API key from the [cloro dashboard](https://dashboard.cloro.dev/) and set it as an environment variable (`CLORO_API_KEY`)

## 工具

cloro provides several tools for scraping AI platforms and extracting structured data. To use these tools:

```python
from langchain_cloro import CloroGoogleSearch, CloroChatGPT, CloroGemini, CloroPerplexity, CloroGrok, CloroCopilot
```

For detailed documentation and examples, see:
- [Google Search scraper](/oss/python/integrations/tools/cloro#google-search-scraper)
- [ChatGPT scraper](/oss/python/integrations/tools/cloro#chatgpt-scraper)
- [Gemini scraper](/oss/python/integrations/tools/cloro#gemini-scraper)
- [Perplexity scraper](/oss/python/integrations/tools/cloro#perplexity-scraper)
- [Grok scraper](/oss/python/integrations/tools/cloro#grok-scraper)
- [Copilot scraper](/oss/python/integrations/tools/cloro#copilot-scraper)

For more information, visit the [cloro documentation](https://docs.cloro.dev).
