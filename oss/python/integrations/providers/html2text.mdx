>[html2text](https://github.com/Alir3z4/html2text/) is a Python 包 that converts a page of `HTML` into clean, easy-to-read plain `ASCII text`.

The ASCII also happens to be a valid `Markdown` (a text-to-HTML format).

## 安装和设置

<CodeGroup>
```bash pip
pip install html2text
```

```bash uv
uv add html2text
```
</CodeGroup>

## 文档转换器

查看[使用示例](/oss/python/integrations/document_transformers/html2text).

```python
from langchain_community.document_loaders import Html2TextTransformer
```
