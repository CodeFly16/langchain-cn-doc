        ## UI 框架集成

        即插即用的 UI 组件库，开箱即用地与 `@langchain/react` 配合工作。

        <CardGroup cols={1}>
        <Card title="ai-elements" icon="package" href="https://ui-patterns.langchain.com/ai-elements/" cta="打开预览" target="_blank">
            无头、可组合的 React 组件，用于构建 AI 聊天界面。底层使用 `useStream`，完全兼容 shadcn/ui。

            - 滚动吸附的对话容器
            - 带语法高亮的流式代码块
            - 可折叠的推理/思考区块
            - 工具调用显示（参数和结果）
            - 微光加载状态和建议标签
        </Card>
        <Card title="assistant-ui" icon="package" href="https://ui-patterns.langchain.com/assistant-ui/" cta="打开预览" target="_blank">
            Claude 风格的助手界面，使用 `@assistant-ui/react` 原语通过 `useExternalStoreRuntime` 连接到 LangChain。

            - Claude 风格的暖色羊皮纸主题
            - 可折叠的思维链推理
            - 图片附件支持
            - 复制/点赞/点踩操作栏
            - 完整的深色模式支持
        </Card>
        <Card title="OpenUI" icon="package" href="https://ui-patterns.langchain.com/openui/" cta="打开预览" target="_blank">
            生成式 UI 聊天，LangChain 智能体在消息流中发出任意 React 组件——在浏览器中实时渲染。

            - 智能体驱动的动态组件渲染
            - 流式消息组合
            - 自定义组件注册表
            - 生成界面的实时预览
        </Card>
        </CardGroup>
